# 应用升级与回滚

中央库发布版本不直接替换应用生产代码。推荐流程：

1. 下载固定 tag 的 bundle 和 SHA256。
2. 在临时目录验证每个文件及总 `bundleSha256`。
3. 运行中央库测试和应用自己的全部测试。
4. 使用相同输入做新旧版本影子解析，比较记录标题、URL、数量和 diagnostics。
5. 新版本少取记录、增加静默空结果或出现未解释诊断时拒绝升级。
6. 全绿后将 vendor 目录原子切换到新版本。
7. 保留上一版本目录和版本清单。

回滚只需把应用导入路径或目录指针切回上一份已验证 bundle。升级检查失败不得删除旧版本，也不得阻塞应用原有业务任务。

应用应记录：当前版本、候选版本、SHA256、测试结果、影子差异、切换时间和回滚结果。
