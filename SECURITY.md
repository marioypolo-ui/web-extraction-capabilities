# Security Policy

## Supported versions

Only the latest tagged release is supported during the initial `0.x` phase.

## Reporting

Do not open a public issue containing credentials, private URLs, browser state, or exploit details. Use GitHub private vulnerability reporting when enabled.

## Boundaries

- Use website capabilities only on public resources or systems you are authorized to access.
- The project does not bypass CAPTCHA, sliders, access controls, or rate limits.
- Credentials and browser profiles belong to the consuming application.
- Fixtures must be synthetic or sanitized.
- A successful test does not grant permission to scan a third-party system.
